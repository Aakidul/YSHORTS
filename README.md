# YSHORTS


Y Shorts is a fully automated Python 3-based YouTube Shorts generation system designed to convert real-time news into engaging short-form videos without human intervention. It pulls fresh content from RSS feeds, processes headlines and summaries, and intelligently pairs them with relevant images to create visually appealing storytelling clips. The system then generates natural-sounding voiceovers using Text-to-Speech (TTS) technology, ensuring each video has clear narration.

Once the media assets are assembled, Y Shorts automatically renders vertical 10-second videos optimized for YouTube Shorts format. The entire pipeline—from news ingestion, content filtering, script formation, audio generation, video assembly, to final rendering—is fully automated. It is built for scalability, making it suitable for running faceless news channels, automated media pipelines, and AI-driven content farms. Y Shorts eliminates manual editing and publishing effort, enabling continuous, high-speed content production with minimal cost and maximum efficiency.
